## 3. Deep-dive Dedup

- **Nenhuma UNIQUE constraint** em `leads(account_id, phone)` nem em `leads(account_id, wa_remote_jid)`. DB sem safety-net.
- Race não materializa hoje (better-sqlite3 sync), mas basta multi-réplica pra abrir porta.
- Duplicatas históricas continuam livres.

### UNIQUE obrigatório
```sql
CREATE UNIQUE INDEX ux_leads_account_phone ON leads(account_id, phone) WHERE phone IS NOT NULL;
CREATE UNIQUE INDEX ux_leads_account_wajid ON leads(account_id, wa_remote_jid) WHERE wa_remote_jid IS NOT NULL;
```

### Nome esquisito
- Sem sanitização de pushName: emoji, zero-width, RTL override (`U+202E` inverte texto), string 500+ chars.
- Sem trim: `pushName = "   "` passa como truthy.
**Fix:** helper `sanitizeName` com NFC + strip controles + trim + slice(0, 80).

### Update de name funciona como user quer?
**Quase.** Regra "nunca sobrescrever nome real" ok. MAS não cobre placeholder `Contato @lid ...` (fix C), name all-digit (10 casos hoje), name = phone com formatação diferente.

**Fix:** condição unificada com `isPlaceholderName`.
